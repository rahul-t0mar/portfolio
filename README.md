## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/rahul-t0mar/portfolio.git
```

Go to the project folder:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```
